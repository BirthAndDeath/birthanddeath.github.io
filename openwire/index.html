OpenWire

一个跨平台 P2P 聊天应用，采用后量子端到端加密。基于 libp2p 构建 P2P 网络，桌面端使用 Tauri 2 + SvelteKit，并提供 ratatui 终端界面。

开发中 Rust libp2p Tauri 2 SvelteKit AGPL-3.0
GitHub 仓库 ↗
仅供演示，生产自负，未经审计。

亮点

  • 后量子 E2EE — ML-DSA-65 + ML-KEM-768 + AES-GCM。
  • P2P 网络与 NAT 穿透 — libp2p（QUIC / TCP / WebSocket / mDNS / Kademlia DHT），以及 Circuit Relay v2、DCUtR、AutoNAT。
  • 文件传输 — 分片流式、断点续传、完整性校验；离线队列在联系人上线后自动重试。
  • 多端形态 — ratatui TUI / JSON CLI，以及 Tauri 2 + SvelteKit 桌面端，跨 Windows / macOS / Linux。
